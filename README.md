## Descripción

Este proyecto implementa un servicio web para realizar el registro y el inicio de sesión de usuarios.

El servicio recibe un usuario y una contraseña y permite comprobar si los datos de autenticación son correctos.

- Express
- JavaScript
- Visual Studio Code
